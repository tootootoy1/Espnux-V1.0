**Espnux**

Board: Esp32-S3-N16R8 (try it on your board)

Buttons:

> Key "OK" pin15 -> GND

> Key "Left" pin4 -> GND

> Key "Up" pin5 -> GND

> Key "Down" pin6 -> GND

> Key "Right" pin7 -> GND

Display: ssd1306 oled display 0.96 inch (0x3C) (resolution 128x64)



Available commands:

> help

> espnux

> espfetch

> clear

> author

> wifi (Soon...)

> ledON (Soon...)

> ledOFF (Soon...)
